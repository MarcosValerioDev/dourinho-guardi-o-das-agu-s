## 📥 Como rodar o projeto
Instruções passo a passo de como clonar e executar o ambiente localmente:

1. Clone este repositório:
   ```bash
   git clone https://github.com/MarcosValerioDev/dourinho-guardi-o-das-agu-s.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd nome-do-projeto
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Inicie a aplicação:
   ```bash
   npm run dev
   ```
